Despliegue Multi-sitio LAMP

Documentación técnica del entorno estático sin dominio definido

Arquitectura del Entorno

El objetivo principal de esta configuración es alojar dos sitios web estáticos independientes (un currículum y un portfolio profesional) dentro del mismo servidor web Apache bajo una máquina virtual Linux, operando sin un nombre de dominio completamente cualificado (FQDN).

El acceso a los recursos se gestiona mediante rutas diferenciadas bajo el DocumentRoot (/var/www/html/cv/ y /var/www/html/portfolio/), asegurando la correcta resolución de rutas relativas tanto para hojas de estilo en cascada como para scripts de interacción.

Resolución y Mantenimiento

Durante la configuración se verificaron los permisos de lectura y ejecución para el usuario del servidor (www-data) y la integridad de los enlaces entre páginas múltiples en cada proyecto. Esta infraestructura sirve como paso previo al despliegue en entornos de alojamiento externos como GitHub Pages.
